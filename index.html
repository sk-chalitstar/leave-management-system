การเชื่อมต่อ Google Sheets API (Google Apps Script)

ใช้ Google Sheets เป็นฐานข้อมูลฟรี Real-time และบันทึกไฟล์แนบลง Google Drive อัตโนมัติ

นำ Web App URL ที่ได้จากการ Deploy Google Apps Script มาใส่ที่นี่ แล้วกดบันทึก

ขั้นตอนการตั้งค่าผูก Google Sheets ใน 4 ขั้นตอน:
  1. สร้าง Google Sheet ใหม่ขึ้นมา 1 ไฟล์ที่ Google Drive ของท่าน
  2. ไปที่เมนู ส่วนขยาย (Extensions) > Apps Script
  3. คัดลอกโค้ดจากไฟล์ google-apps-script/Code.gs ไปวางทับโค้ดเดิมทั้งหมด แล้วกดบันทึก (Ctrl + S)
  4. กดปุ่ม ทำให้ใช้งานได้ (Deploy) > การทำให้ใช้งานได้รายการใหม่ (New deployment) > เลือกประเภทเป็น Web app
    • Execute as: Me (บัญชีของคุณ)
    • Who has access: Anyone (ทุกคน)
  5. คัดลอก Web app URL ที่ได้มาใส่ในช่องด้านบนนี้แล้วกดบันทึก
