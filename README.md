# LeaveFlow Pro - ระบบจัดการบันทึกการลางานแบบครบวงจร (Leave Management System)

ระบบจัดการการลางานระดับสากล ทำงานในรูปแบบ Client-Side Web Application ที่สามารถนำขึ้นรันบน **GitHub Pages** ได้ 100% โดยเชื่อมโยงฐานข้อมูลกับ **Google Sheets** และบันทึกไฟล์แนบลง **Google Drive** ผ่าน Google Apps Script Web App API ฟรี โดยไม่ต้องเสียค่าโฮสติ้งหรือฐานข้อมูลใดๆ

---

## 🌟 ฟังก์ชันเด่นของระบบ (Core Features)

1. **Dashboard & Analytics**
   - KPI ภาพรวม: กำลังลาในวันนี้, คำขอรออนุมัติ, อนุมัติในเดือนนี้, จำนวนพนักงาน
   - กราฟสัดส่วนการลาแต่ละประเภท (พักร้อน, ลากิจ, ลาป่วย, ลาอื่นๆ) ด้วย Chart.js
   - กราฟแท่งสถิติวันลาสะสมแยกตามแผนก (Department Leave Statistics)
   - ตารางคำขอล่าสุด 5 รายการ พร้อมกดดูและอนุมัติได้ทันที

2. **ระบบคำนวณวันลาอัจฉริยะ (Smart Workday Calculation)**
   - คำนวณวันลาสุทธิตามปฏิทินจริง **โดยตัดวันหยุดเสาร์-อาทิตย์ และตัดวันหยุดนักขัตฤกษ์ในระบบออกให้อัตโนมัติ**
   - รองรับการลาเต็มวัน และการลาครึ่งวัน (ครึ่งวันเช้า 0.5 วัน / ครึ่งวันบ่าย 0.5 วัน)
   - ระบบแจ้งเตือน Real-time ทันที หากวันที่ขอยื่นลาเกินกว่าสิทธิ์วันลาคงเหลือ

3. **ค้นหาพนักงาน & ตรวจสอบโควตาวันลาคงเหลือ (Employee Quota & Balances)**
   - ค้นหาพนักงานจาก **เลขประจำตัวพนักงาน (Emp ID)** หรือ **ชื่อพนักงาน**
   - แสดงสิทธิ์วันลาคงเหลือ: พักร้อนคงเหลือ, ลากิจคงเหลือ, ลาป่วยคงเหลือ, ลาอื่นๆ
   - หักลบวันลาจากโควตาทันทีเมื่อมีการอนุมัติคำขอ
   - เพิ่ม/แก้ไขข้อมูลพนักงาน กำหนดโควตารายปีได้อิสระ

4. **ปฏิทินวันหยุดนักขัตฤกษ์ (Holiday Manager)**
   - สามารถเข้าไปเพิ่ม/แก้ไข/ลบ วันหยุดประจำปีได้เอง
   - มีปุ่ม **"โหลดวันหยุดไทยมาตรฐาน"** เพื่อนำเข้าวันหยุดราชการและวันหยุดนักขัตฤกษ์ไทยประจำปีลงระบบในคลิกเดียว

5. **แนบไฟล์และรูปภาพหลักฐานได้มากกว่า 1 ไฟล์ (Multi-attachments)**
   - รองรับทั้งการลากวาง (Drag & Drop) หรือเลือกไฟล์
   - แนบได้หลายไฟล์ เช่น ใบรับรองแพทย์, ใบจองตั๋วเดินทาง, เอกสารทางราชการ
   - มีระบบ Preview รูปภาพขนาดจริง และเปิดดู/ดาวน์โหลดไฟล์ได้จากหน้าอนุมัติ
   - ไฟล์จะถูกอัปโหลดขึ้น **Google Drive** ในโฟลเดอร์ `Leave_Attachments` ให้อัตโนมัติ

6. **ระบบอนุมัติและการตรวจสอบ (Leave Approvals & Tracking)**
   - แถบกรองสถานะ: ทั้งหมด / รออนุมัติ (Pending) / อนุมัติแล้ว (Approved) / ไม่อนุมัติ (Rejected)
   - มีช่องระบุเหตุผลเมื่อไม่อนุมัติ (Rejection reason)

7. **พิมพ์ใบลาทางการ & ออกรายงานย้อนหลัง (Official Slip & Reports)**
   - **Official Leave Slip**: สามารถพิมพ์แบบฟอร์มใบขอลาอย่างเป็นทางการที่มีลายเซ็นผู้ขอลา, หัวหน้างาน และฝ่ายบุคคล (Printable A4 Leave Slip)
   - **Report Generator**: กรองข้อมูลประวัติการลาย้อนหลังตามช่วงวันที่, แผนก, พนักงาน, หรือประเภทการลา
   - **Export to Excel (.xlsx)**: ดาวน์โหลดตารางรายงานเป็นไฟล์ Excel ได้ทันทีด้วย SheetJS
   - **Print Report**: สั่งพิมพ์รายงานประวัติการลาเป็น PDF / Paper

8. **รองรับ 2 โหมดการทำงาน (Live & Offline Demo)**
   - **Live Mode**: ซิงค์ข้อมูลสองทางกับ Google Sheets & Google Drive
   - **Offline / Demo Mode**: ทำงานผ่าน LocalStorage ทันทีโดยไม่ต้องตั้งค่าใดๆ เหมาะสำหรับทดลองระบบ

## 🚀 วิธีติดตั้งและรันบน GitHub Pages (Step-by-Step)

### 1. นำไฟล์ขึ้น GitHub
1. สร้าง New Repository บน GitHub (เช่น `leave-management-system`)
2. อัปโหลดไฟล์ทั้งหมดในโปรเจกต์นี้ขึ้นไปที่ Repository
3. ไปที่แท็บ **Settings** ของ Repository &gt; **Pages**
4. ในหัวข้อ **Build and deployment**:
   - Source: เลือก **Deploy from a branch**
   - Branch: เลือก **main** หรือ **master** และโฟลเดอร์ **/(root)**
   - กด **Save**
5. รอประมาณ 1-2 นาที คุณจะได้ URL เว็บไซต์ เช่น:  
   `https://<your-username>.github.io/leave-management-system/`

## 📊 วิธีผูก Google Sheets เป็น Database ผ่าน Google Apps Script

### ขั้นตอนที่ 1: สร้าง Google Sheet
1. เปิด [Google Drive](https://drive.google.com/) แล้วสร้าง **Google Sheets (สเปรดชีตใหม่)** ตั้งชื่อตามต้องการ เช่น `Leave_Management_DB`

### ขั้นตอนที่ 2: ติดตั้งสคริปต์ Google Apps Script
1. ในหน้า Google Sheet ที่สร้าง ไปที่เมนูด้านบน: **ส่วนขยาย (Extensions)** &gt; **Apps Script**
2. ลบโค้ดเดิมในไฟล์ `Code.gs` ออกทั้งหมด
3. คัดลอกโค้ดจากไฟล์ `google-apps-script/Code.gs` ในโปรเจกต์นี้ มาวางลงไปแทนที่ทั้งหมด
4. กดบันทึก (Ctrl + S หรือคลิกไอคอนแผ่นดิสก์)

### ขั้นตอนที่ 3: ทำให้ใช้งานได้ในรูปแบบ Web App (Deploy)
1. คลิกปุ่มสีน้ำเงิน **ทำให้ใช้งานได้ (Deploy)** มุมบนขวา &gt; เลือก **การทำให้ใช้งานได้รายการใหม่ (New deployment)**
2. คลิกไอคอนรูปเฟือง (⚙️) ข้างประเภท &gt; เลือก **เว็บแอป (Web app)**
3. กรอกข้อมูลการ Deploy ดังนี้:
   - **คำอธิบาย (Description):** `Leave API Production`
   - **เรียกใช้ในฐานะ (Execute as):** `ฉัน (Me / บัญชี Google ของคุณ)`
   - **ผู้มีสิทธิ์เข้าถึง (Who has access):** `ทุกคน (Anyone)` *(สำคัญมาก เพื่อให้เว็บ GitHub Pages ส่งข้อมูลมาได้)*
4. คลิก **ทำให้ใช้งานได้ (Deploy)**
5. กดยอมรับสิทธิ์ (Authorize access) และเลือกบัญชี Google ของคุณ
6. คัดลอก **URL เว็บแอป (Web app URL)** ที่ลงท้ายด้วย `/exec`

### ขั้นตอนที่ 4: เชื่อมต่อใน Web App
1. เปิด Web App LeaveFlow Pro บนบราวเซอร์ของคุณ
2. ไปที่เมนู **"เชื่อมต่อ Google Sheets"** (หรือแท็บ Settings)
3. วาง Web App URL ที่ได้ลงในช่อง **Google Apps Script Web App URL**
4. กดปุ่ม **"ทดสอบการเชื่อมต่อ"** หากสำเร็จจะมีข้อความแจ้งเตือนสีเขียว
5. กดปุ่ม **"บันทึกการตั้งค่า"**
6. ระบบจะเริ่มซิงค์ข้อมูลกับ Google Sheets และ Google Drive ทันที!
